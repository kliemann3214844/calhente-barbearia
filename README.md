## 🚀 Como Hospedar

### 1. No Netlify (Método Super Rápido - Netlify Drop)
1. Acesse [app.netlify.com/drop](https://app.netlify.com/drop)
2. Arraste e solte o arquivo `calhente-barbearia-dist-pronto-para-hospedar.zip` (ou extraia e arraste a pasta `dist`).
3. Seu site estará online imediatamente com certificado SSL gratuito!

### 2. No Netlify via Git / GitHub
1. Suba os arquivos do projeto para o GitHub.
2. No Netlify, clique em **Add new site > Import an existing project**.
3. Selecione o repositório.
4. As configurações já estão prontas no arquivo `netlify.toml`:
   - **Build command:** `npm run build`
   - **Publish directory:** `dist`
5. Clique em **Deploy**.

### 3. No Lovable / Vercel
1. No Lovable, importe o arquivo `calhente-barbearia-projeto-completo.zip` ou conecte via GitHub.
2. O projeto utiliza React 19 + Vite + Tailwind CSS.
